# Anwar Cement Sheet – Image Generation Prompts

One prompt per image. Generate in Google Flow (or Gemini / Nano Banana Pro), then save
each file with the exact name and folder shown. The website picks them up automatically.

## Global style (paste this line at the start of every prompt)

> Ultra-realistic photograph, natural colours, sharp detail, light-grey corrugated fibre cement
> roofing sheets (not shiny metal), rural/industrial Bangladesh, typical Bangladeshi people
> and clothing, no text, no logos, no watermark.

# Tips

- Ask for all images of one section in the same chat so lighting and style stay consistent.
- If people look Indian or Western, add: "typical Bangladeshi village clothing and faces".
- If any text or watermark appears, reply: "same image, remove all text and watermarks".
- If the aspect ratio is wrong, reply with the exact size, e.g. "make it 16:9, 1920 by 1080".
- Keep the roof colour light grey (natural cement sheet) in every image so the site feels
  like one campaign.
